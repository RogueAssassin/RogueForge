# RogueForge 0.8.2 release

RogueForge 0.8.2 is the single-runtime consolidation release. The complete server-side application now lives in `rogueforge.py`; historical version wrappers and runtime extension modules are removed.

Use `./update.sh latest` for the current main/GHCR latest build, or `./update.sh 0.8.2` once the release tag is published.
